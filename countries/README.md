# Country folders (road signs by country)

## Naming convention

- **Computer-friendly**: lowercase, no spaces, hyphens for multi-word names.
- **English spelling**: use the correct English name of the country.

Examples:

| Folder name       | English name    |
|-------------------|-----------------|
| austria           | Austria         |
| belgium           | Belgium         |
| bulgaria          | Bulgaria        |
| czech-republic    | Czech Republic  |
| denmark           | Denmark         |
| estonia           | Estonia         |
| finland           | Finland         |
| france            | France          |
| germany           | Germany         |
| latvia            | Latvia          |
| lithuania         | Lithuania       |
| portugal          | Portugal        |
| slovakia          | Slovakia        |
| spain             | Spain           |
| sweden            | Sweden          |

To add or rename folders, use the same rules: `lowercase-with-hyphens`, English.
